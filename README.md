I created a banking application using JavaScript that allows users to manage their accounts through a simple and interactive interface.
It takes in a sign up inputs and displays the new accounts account number and allows for someone to deposit and withdraw from the account as they want 

One of the main things I focused on was making sure the application responds correctly to different user actions and prevents invalid transactions.
This project helped me improve my understanding of JavaScript, especially variables, functions, objects, conditionals, and manipulating the DOM.
the main concepts used are:
-objects = to hold all the values of the account
-if statements = to check values against eachother
-getElementbyId() = A method that i used to get the inputs given by the user
-map() = i used this to create a new object
-functions = used to make the processes happen
-parameters = used to get the value and pass into the functions
